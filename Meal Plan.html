      Deploy to GitHub Pages

      1. Create a public repository on GitHub (e.g., meal-plan).
      2. Commit and push this code as index.html in the repository root.
      3. Open your repository Settings > Pages.
      4. Under Source, select Deploy from a branch, set branch to main and directory to / (root).
      5. Click Save. Your planner is live on GitHub Pages.
